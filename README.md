# text_utils
In this repository you will find the basic functions that we can use to manipulate strings and texts in general.

The package provides the following functions:

- word_count
- character_count
- reverse
- capitalize_words
- shuffle_words

`shuffle_words(text)` returns the words in a random order. Words are separated
by whitespace, punctuation stays attached to its word, and whitespace in the
result is normalized to single spaces.
